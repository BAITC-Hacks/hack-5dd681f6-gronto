# План закупок

Локальный сайт для подготовки заказов поставщикам по выгрузкам IEK и Systeme Electric.
Он показывает прогноз, рекомендуемое количество, причину расчёта и риск дефицита.
Менеджер может поправить количество и скачать CSV. Заказы поставщикам не отправляются.

## Запуск на своём компьютере

Нужны Python 3.11–3.13, интернет при первом запуске для установки зависимостей и
предоставленные ZIP-архивы. ZIP не требуется распаковывать. Файлы с исходными
выгрузками не включены в репозиторий.

**Windows:** дважды нажмите `run.bat` (установленный Python должен поддерживать
команду `py -3`). **macOS/Linux:** в терминале запустите `sh run.sh`.
Первый запуск создаст окружение и установит зависимости. Последующие запускаются
из уже готового окружения. Для ручной установки выполните команды ниже.

```bash
python -m venv .venv
```

Активируйте окружение: Windows PowerShell — `.venv\Scripts\Activate.ps1`, macOS/Linux —
`source .venv/bin/activate`. Затем:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откройте адрес, показанный в терминале (обычно `http://localhost:8501`).
Загрузите один или оба ZIP в боковой панели, проверьте параметры и нажмите «Рассчитать».
Данные обрабатываются в памяти локального процесса. Для остановки нажмите Ctrl+C в терминале.

## Данные и ограничения

Сайт читает помесячные продажи, историю операций, кратность заказа, остатки и товары
в пути. Связь между файлами устанавливается по коду 1С. Последний неполный месяц
не используется для определения обычного месячного спроса. Прогноз строится на
взвешенной истории последних шести завершённых месяцев с сезонным коэффициентом.
Сезонность рассчитывается по полным 2024–2025 годам; при редкой истории артикула
используется сезонность поставщика. Устойчивый рост оценивается по двум соседним
трёхмесячным периодам, а дополнительный прирост задаётся вручную.

Редкие крупные продажи в одном документе ограничиваются по медиане размера операции
для артикула. Их превышение исключается из регулярного месячного спроса. Если таких
продаж много, они считаются повторяющимися. В выгрузке нет ID клиента, поэтому
определить именно крупный заказ одного клиента пока невозможно.

Если загружен журнал stockout, отсутствовавший спрос оценивается по соседним месяцам.
Без журнала корректировка не применяется. Для IEK остаток из архива относится к
началу сентября 2026 года. Для Systeme Electric берётся «Свободный остаток» из
сводной таблицы без подтверждённой даты. Поэтому **до рабочего заказа** загрузите
актуальные остатки. Сроки новой поставки (по умолчанию 30 дней) — демонстрационные
параметры. Товар в пути без даты прибытия отображается, но не вычитается.

Дополнительные файлы CSV кодируются UTF-8 и имеют заголовок:

```csv
supplier,code,balance
IEK,010500003_,48
```

```csv
supplier,code,start,end
IEK,010500003_,2026-08-01,2026-08-07
```

Значение `supplier` — точно `IEK` или `Systeme Electric`. Количество к заказу
округляется до указанной кратности; при отсутствии кратности используется 1 и
выводится предупреждение. При отсутствии остатка позиция не получает заказ.
Оценка упущенного спроса, поиск выбросов и коэффициенты роста — подсказки для
менеджера; итог требует проверки перед утверждением.

## Проверка расчёта

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют сроки прибытия, кратность, stockout, исключение разовой крупной
продажи, сезонность и отсутствие фиктивного нулевого остатка. Тест реальных архивов
запускается, если архивы доступны локально по пути `../upload/`.
