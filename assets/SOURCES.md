# Оформление

Оформление адаптировано по https://ekt.kz/ для внутреннего приложения закупок.
Источник проверен 23 сентября 2026 года.

- `ekt-logo.svg` — оригинальный SVG из шапки ekt.kz. Знак принадлежит ГК «Электрокомплект».
- Цвета сайта: `#2C7294`, `#F4B301`, `#0B4366`; основной шрифт — PT Sans.
- `pt-sans-regular.ttf` и `pt-sans-bold.ttf` — PT Sans из Google Fonts,
  https://fonts.google.com/specimen/PT+Sans. Лицензия: `PT-Sans-OFL.txt`.

Логотип и шрифты встроены локально: интерфейс не обращается к внешним сайтам
для загрузки оформления. Стили приложения написаны отдельно от CSS сайта.
